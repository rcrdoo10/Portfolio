# Portfolio
Portfolio Website

Website portfolio pribadi yang menampilkan profil, skills, project, dan kontak saya. Dibuat dengan HTML, CSS, dan JavaScript murni tanpa framework.

Fitur:
- Loading screen dengan progress bar dan persentase
- Typing effect bergantian antara Web Development, Data Analyst, dan Machine Learning
- Smooth scroll antar section
- Menu navbar otomatis ter-highlight saat scroll
- Marquee text berjalan sebagai jembatan antar section
- Tab toggle antara Projects dan Tech Stack
- Dark mode dengan penyimpanan preferensi
- Responsive layout
- Icon tech stack dengan warna brand asli

Tech Stack:
- HTML5
- CSS3
- JavaScript (Vanilla)
- Google Fonts (Poppins)
- Devicon
- Git dan GitHub

Struktur Folder:
portfolio/
  index.html
  style.css
  script.js
  README.md
  image/MySelf.jpeg

Cara Menjalankan:
1. Clone repository: git clone https://github.com/rcrdoo10/portfolio.git
2. Masuk ke folder: cd portfolio
3. Buka file index.html di browser

Kustomisasi:
- Ganti data pribadi di index.html
- Ganti foto di folder image dengan nama file MySelf.jpeg
- Ganti warna di style.css
